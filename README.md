## ⚡ Lite vs. Pro Edition
- **Lite Edition (This Repo)**: Core CSS variables & live browser token generator.
- **Pro Edition (`.zip` Bundle)**: Complete modular CSS3 design system, 5 aesthetic presets (`OLED Emerald`, `Cyberpunk Neon`, `Nordic Frost`, `Amber Bento`, `Titanium Minimal`), automatic Dark/Light mode, 60fps micro-interactions, offline visual configurator, bilingual guide (EN/ES), and commercial license.
